# Claims and safety boundary

## Acceptable prototype language

- personal light exposure;
- spectral light sensing;
- estimated melanopic EDI (development calibration);
- time-aware lighting target;
- circadian-supportive lighting;
- visual-comfort lighting;
- focus lighting scene;
- travel light plan / adherence sensing;
- closed-loop environmental control.

## Language we do not use without appropriate evidence / regulatory analysis

- treats depression / SAD;
- cures jet lag;
- prevents eye damage;
- clinically improves sleep;
- medically optimizes circadian rhythm;
- medical-grade melanopic measurement;
- guarantees cognitive performance.

## Control safety

The software controller has explicit limits for command magnitude, brightness, iteration count, total duration, stale physical sensor data and manual stop. Future hardware adds thermal, battery, charge and wear-state protections.

## Prototype disclaimer

The current system is an engineering prototype. It is not a medical device and is not intended for diagnosis, treatment, prevention or cure of disease.
