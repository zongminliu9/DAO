# Proposed use of funds

These are **planning ranges, not vendor quotes**. The point is to show what capital unlocks and which spend is gated by evidence.

| Workstream | Planning range | What it buys |
|---|---:|---|
| Rev A electronics + PCB spins | $25k–$35k | rigid-flex prototypes, assembly, debug fixtures, spare boards/components |
| Optical prototypes + calibration | $20k–$30k | diffuser/aperture variants, reference-instrument/lab access, test fixtures |
| Mechanical / industrial design EVT | $20k–$30k | shell/clip iterations, CNC/resin/metal prototypes, fit/comfort fixtures |
| Pilot inventory + charging fixtures | $15k–$25k | small batch of pilot devices, batteries, charging hardware, spares |
| Testing / pre-compliance / RF learning | $10k–$20k | early EMC/RF/safety learning before expensive design lock |
| Pilot operations + field validation | $10k–$15k | controlled user testing, travel/lighting environments, data capture |
| Contingency for hardware iteration | remainder | absorbs inevitable sensor/battery/mechanical re-spins |

## Spend gates

1. Do not order a large PCB batch before optical placement is validated.
2. Do not freeze battery volume before measuring real current draw.
3. Do not commit to metal enclosure geometry before antenna testing.
4. Do not scale pilot inventory before calibration and data-quality flags are credible.
